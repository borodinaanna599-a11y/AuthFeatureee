# RUNBOOK — AuthFeature

## 1. Назначение

Документ описывает порядок мониторинга, диагностики и устранения проблем Android-приложения AuthFeature.

## 2. Используемые инструменты мониторинга

- **Firebase Crashlytics** — сбор информации о сбоях приложения.
- **Firebase Remote Config** — удалённое управление функциями приложения.
- **Firebase App Distribution** — распространение тестовых сборок.

## 3. Контроль состояния приложения

Основные показатели:

- Количество аварийных завершений приложения.
- Количество пользователей, столкнувшихся со сбоями.
- Частота повторяющихся ошибок.
- Успешность загрузки параметров Remote Config.

## 4. Порядок действий при обнаружении сбоя

1. Открыть Firebase Console.
2. Перейти в раздел Crashlytics.
3. Найти зарегистрированную ошибку.
4. Изучить stack trace и определить проблемный участок кода.
5. Исправить ошибку в Android Studio.
6. Выполнить сборку и проверить приложение.
7. Подготовить новую тестовую версию.

## 5. Управление функциями через Remote Config

Используются следующие параметры:

| Параметр | Назначение |
|---|---|
| welcome_text | Текст приветствия |
| welcome_banner_enabled | Включение приветствия |
| add_note_enabled | Включение добавления заметок |

При обнаружении проблем соответствующую функцию можно временно отключить через Firebase Remote Config.

## 6. Критерии успешной работы

- Приложение запускается без ошибок.
- Авторизация работает корректно.
- Заметки добавляются и отображаются.
- Firebase Remote Config получает параметры.
- Crashlytics подключён для регистрации сбоев.

## 7. Итог

Для проекта AuthFeature настроены инструменты мониторинга и удалённого управления функциями. При обнаружении ошибок предусмотрен порядок диагностики, исправления и повторного тестирования.
